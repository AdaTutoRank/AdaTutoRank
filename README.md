## ⚡ 1. How to run AdaTutoRank

### 🔎 1.1 Deep Research Evaluation

For environment setup, refer to the official
[DR-Tulu repository](https://github.com/rlresearch/dr-tulu.git).

Set `SERPER_API_KEY` and `OPENAI_API_KEY` in `dr-tulu/agent/.env`.

**a.** Launch [DR-Tulu-8B (`step_1900`)](https://huggingface.co/rl-research/DR-Tulu-8B/tree/step_1900):

```bash
CUDA_VISIBLE_DEVICES=0,1,2,3 \
vllm serve rl-research/DR-Tulu-8B \
  --revision step_1900 \
  --dtype auto \
  --port 30001 \
  --max-model-len 40960 \
  --tensor-parallel-size 4 \
  --gpu-memory-utilization 0.8
```

**b.** Launch the webpage summarization model:

```bash
CUDA_VISIBLE_DEVICES=4,5 \
vllm serve Qwen/Qwen3-8B \
  --dtype auto \
  --port 30002 \
  --max-model-len 40960 \
  --tensor-parallel-size 2 \
  --gpu-memory-utilization 0.8
```

**c.** Download [AdaTutoRank-8B](https://huggingface.co/kailinjiang/AdaTutoRank-8B) and launch it from `{ADATUTORANK_PATH}`:

```bash
CUDA_VISIBLE_DEVICES=6,7 \
vllm serve {ADATUTORANK_PATH} \
  --port 30003 \
  --dtype bfloat16 \
  --served-model-name adatutorank \
  --max-model-len 40960 \
  --tensor-parallel-size 2 \
  --gpu-memory-utilization 0.8
```

**d.** Optionally start MCP manually; inference starts it when needed:

```bash
cd dr-tulu/agent
python -m dr_agent.mcp_backend.main --transport streamable-http --host 0.0.0.0 --port 8000
```

**e.** Run inference and scoring:

```bash
cd dr-tulu/agent
bash inference.sh --reranker adatutorank_8b
```

Run `bash inference.sh --help` for optional arguments. For baselines, launch the
corresponding reranker and pass its name to `--reranker`.

```text
Available rerankers: no_rerank, bge_reranker_large, monot5_3b, rankt5_3b, rankllama_7b, rankvicuna_7b, rankzephyr_7b, rearank_7b, reasonrank_7b, rank4gen_8b, setr_8b, rubricranker_8b, adatutorank_8b
```

Configuration:

```text
configs/
├── models.yaml             model repositories, local paths, and server settings
├── rerankers.yaml          reranker runtime settings
└── prompts/<name>.yaml     reranker prompts
```

Servers can also be launched with `bash serve.sh <name> --gpus 6,7`.

### 📚 1.2 RAG Evaluation

RAG evaluation runs independently in `Rankify/`, comparing rerankers on BM25
top-50 candidates from five QA benchmarks. Answers are generated by
[Llama-3.1-8B-Instruct](https://huggingface.co/meta-llama/Llama-3.1-8B-Instruct).
For environment setup, refer to the official
[Rankify repository](https://github.com/DataScienceUIBK/Rankify.git).

Download the [BM25 top-50 data](https://huggingface.co/datasets/kailinjiang/rag-bm25-top50):

```bash
huggingface-cli download kailinjiang/rag-bm25-top50 --repo-type dataset --local-dir data/bm25_top50
```

```
data/bm25_top50/
├── meta.json                       # split, query count and answer hit rate of each benchmark
├── nq/test.jsonl                   # 3,610 queries
├── triviaqa/test.jsonl             # 11,313 queries
├── popqa/test.jsonl                # 14,267 queries
├── 2wikimultihopqa/dev.jsonl       # 12,576 queries
└── bamboogle/test.jsonl            # 125 queries
```

Each line contains one query and 50 BM25 passages:

```jsonc
{
  "id": "nq_test_0",
  "question": "who got the first nobel prize in physics?",
  "answer": "Wilhelm Conrad Röntgen",
  "answers_all": ["Wilhelm Conrad Röntgen"],
  "data_source": "nq",
  "docs": [
    {"original_id": 1, "doc": "receive a diploma, a medal and a document confirming the prize amount. Nobel Prize in Physics ...",
     "title": "Nobel Prize in Physics", "bm25_score": 16.33, "passage_id": 628725, "has_answer": false},
    ...
  ]
}
```

`original_id` is the 1-based BM25 rank; `answers_all` contains the gold aliases.

```bash
GPU_IDS="0 1 2 3" DATASETS="nq popqa" bash run_rag_eval.sh adatutorank-8b setr-8b
```

Outputs are grouped by benchmark and reranker:

```
outputs/bm25_top50/
└── <benchmark>/<reranker>/
    ├── ranker_cache.jsonl                         # reranked / selected passages per query
    ├── ranker_eval.json                           # answer-recall statistics of the reranker
    └── meta-llama_Llama-3.1-8B-Instruct/
        ├── output.jsonl                           # generated answer + scores per query
        └── output_eval_summary.json               # EM / F1 / contains-match over the benchmark
```

Example `output.jsonl` record:

```json
{
  "id": "nq_test_0",
  "data_source": "nq",
  "question": "who got the first nobel prize in physics?",
  "answer": "Wilhelm Conrad Röntgen",
  "answers_all": ["Wilhelm Conrad Röntgen"],
  "selected_docs": [
    {"rank": 1, "original_id": 3, "score": 3.0},

  "context_for_generator": [
    {"original_id": 3, "doc": "Nobel Prize in Physics The Nobel Prize in Physics () is a yearly award ... The first Nobel Prize in Physics was awarded to physicist Wilhelm Röntgen ..."},
    {"original_id": 1, "doc": "receive a diploma, a medal and a document confirming the prize amount. Nobel Prize in Physics ..."},
```

### 📐 1.3 Setwise Evaluation

The SetwiseBench flow follows
[Rubric4Setwise](https://github.com/Rubric4Setwise/Rubric4Setwise). It first
runs the same Rankify rerank-and-generate pipeline, then judges each selected
document set against query-specific rubrics.

The input JSONL uses the RAG schema above and additionally requires
`hybrid_rubrics` with the nine dimensions: Relevance, Authenticity, Quality,
Complementarity, Redundancy, Conflict, Completeness, Density, and Reachability.

#### Short-form

Download `SetwiseEvalKit_short.jsonl` from
[SetwiseEvalKit](https://huggingface.co/datasets/kailinjiang/SetwiseEvalKit):

```bash
cd Rankify
hf download kailinjiang/SetwiseEvalKit SetwiseEvalKit_short.jsonl \
  --repo-type dataset --local-dir data/setwise_eval_kit
```

```bash
export DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxx
GPU_IDS="0 1 2 3" bash run_setwise_eval.sh adatutorank-8b setr-8b
```

#### Long-form

Long-form evaluation runs the same DR-Tulu services as Section 1.1. Download
`SetwiseEvalKit_long.jsonl`, then run one reranker:

```bash
cd dr-tulu/agent
hf download kailinjiang/SetwiseEvalKit SetwiseEvalKit_long.jsonl \
  --repo-type dataset --local-dir data/setwise_eval_kit

export DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxx
bash run_setwise_long_eval.sh --reranker adatutorank_8b
```

For each query, the final judged set is the ordered union of documents selected
by the reranker across all search rounds. Documents are deduplicated by URL
(falling back to title and text), while preserving first-selection order.
Long-form outputs are written to
`dr-tulu/agent/eval_output/setwise_long/<reranker>/`, including the trajectory,
summary, concise judge result, resumable details, and Excel aggregate.

```jsonc
// trajectory.jsonl: round 1 selects [doc-A, doc-B], round 2 selects [doc-B, doc-C]
// all_rankers_summary.jsonl: doc-B is kept once, in its first-seen position
{"id":"q1","selected_docs":{"adatutorank_8b":[1,2,3]}}
```

The judge preserves the original SetwiseBench 0–4 scoring protocol and uses
DeepSeek's official OpenAI-compatible API. It writes:

```text
outputs/setwise_bench/
├── all_rankers_summary.jsonl
├── setwise_judged.jsonl
├── setwise_judged_details.jsonl
└── setwise_judged_stats.xlsx
```

For one query, the key output at each step is:

```jsonc
// ranker_cache.jsonl
{"id":"q1","selected_docs":[{"original_id":3},{"original_id":1}]}

// all_rankers_summary.jsonl
{"id":"q1","selected_docs":{"adatutorank-8b":[3,1]}}

// setwise_judged.jsonl
{"id":"q1","scores_by_ranker":{"adatutorank-8b":{"dimensions":{"Relevance":4.0,"Authenticity":3.5,"Quality":4.0,"Complementarity":3.0,"Redundancy":4.0,"Conflict":null,"Completeness":3.0,"Density":3.5,"Reachability":3.0},"levels":{"Doc-Level":3.8,"Set-Level":3.5,"Global-Level":3.2},"overall":3.5}}}
```

`setwise_judged_details.jsonl` retains evidence and atomic scores for resume and
auditing; the main result contains only dimension, level, and overall scores.

Configuration:

```text
configs/
├── setwise_judge.yaml
└── prompts/setwise_judge.yaml
```



## 🔥 2. How to train AdaTutoRank

### ❄️ 2.1 Setwise-SFT

Install [LLaMA-Factory](https://github.com/hiyouga/LLaMA-Factory), then download
`AdaTutoRank-SFT-Data.json` from
[AdaTutoRank-Train-Data](https://huggingface.co/datasets/kailinjiang/AdaTutoRank-Train-Data)
to:

```
LLaMA-Factory/data/AdaTutoRank-SFT-Data.json
```

```bash
cd LLaMA-Factory
bash run_train.sh
```

### 🎯 2.2 Adaptive Tutoring Optimization (ATO)

Download the ATO splits from
[AdaTutoRank-Train-Data](https://huggingface.co/datasets/kailinjiang/AdaTutoRank-Train-Data):

```text
AdaTutoRank-ATO-Data-Train.parquet  # 3,557 training examples
AdaTutoRank-ATO-Data-Val.parquet    # 100 validation examples
```

Place both files in `ATO/data/`. They can also be downloaded with:

```bash
hf download kailinjiang/AdaTutoRank-Train-Data \
  AdaTutoRank-ATO-Data-Train.parquet AdaTutoRank-ATO-Data-Val.parquet \
  --repo-type dataset --local-dir ATO/data
```

The experiments reported in the paper used a locally deployed
DeepSeek-V4-Flash model as the reward judge. Because that model deployment and
its weights cannot be distributed, the released code provides an implementation
based on DeepSeek's official OpenAI-compatible API instead. This replacement
changes only the model access method: the reward task, rubric prompts, and JSON
output contract remain unchanged. See the
[DeepSeek API documentation](https://api-docs.deepseek.com/zh-cn/) for API-key
setup.

```bash
cd ATO
pip install -e ".[sglang]"

export DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxx
export MODEL_PATH=/path/to/setwise-sft-checkpoint

bash experiments/adatutorank_ato/train_ato.sh
```

The launcher reads both files from `ATO/data/`. Environment variables can
override data, output, and distributed-training settings.
